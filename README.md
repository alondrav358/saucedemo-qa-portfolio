# SauceDemo E-Commerce QA Portfolio (Manual, Cypress & MySQL)

End-to-end Quality Assurance portfolio built by **Alondra Valdez** to demonstrate manual test design, structured defect reporting, automated UI testing with Cypress, and backend SQL data validation on a live web application ([Swag Labs / SauceDemo](https://saucedemo.com)).

---

## Repository Structure

| Folder | Description | Key Artifacts |
| :--- | :--- | :--- |
| **`/manual-testing`** | Functional, negative, and regression testing documentation. | [Test Cases & Bug Reports](./manual-testing/Test_Cases_and_Bugs.md) (8 Test Cases, 4 Critical/High Bugs) |
| **`/cypress-automation`** | Automated UI smoke and regression test scripts written in JavaScript. | [checkout_smoke.cy.js](./cypress-automation/checkout_smoke.cy.js) |
| **`/sql-validation`** | Backend database queries for financial accuracy and data integrity. | [ecommerce_validation.sql](./sql-validation/ecommerce_validation.sql) |

---

## Skills & Tools Demonstrated
* **Test Management & Documentation:** Test Case Design, Boundary/Negative Testing, Defect Lifecycle & Root Cause Reporting.
* **Test Automation:** Cypress (JavaScript), DOM Selectors (`data-test`), Assertions.
* **Database & Data Integrity:** MySQL (`INNER/LEFT JOIN`, `GROUP BY`, `HAVING`, `TIMESTAMPDIFF`), Financial/Tax Reconciliation Checks.
* **Version Control:** Git & GitHub.
